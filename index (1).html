Les 36 traits graphiques CJK sont représentés avec les symboles Unicode dédiés ㇐, ㇑, etc. : ils ne dupliquent donc pas les kanji autonomes 一, 丨, etc. Les noms de formes sont descriptifs ; il ne s’agit pas d’une nomenclature japonaise officielle unique. Les données sont séparées dans fiches.js (une copie lisible est disponible dans fiches.json). Conserve index.html et fiches.js dans le même dossier. Les réponses « Je connais » et « À revoir » sont enregistrées sur cet appareil si ton navigateur autorise le stockage local. Fonctionne sans connexion une fois le fichier ouvert. Astuce : la quatrième face affiche uniquement les composants renseignés et ta phrase de mémorisation, sans image ni texte ajouté automatiquement. Les décompositions sont des aides visuelles, pas des analyses étymologiques. Pour les autres catégories, les trois faces restent inchangées.
